# Security Policy

## Supported versions

Security fixes are provided for the latest v1 release. Users should update to
the newest patch release before reporting an issue.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting form][report]. Include the
affected version, transport, a minimal reproduction, impact, and any suggested
mitigation.

Do not disclose a vulnerability in a public issue before a fix is available.
The maintainers will acknowledge the report, confirm its scope, and coordinate
the fix and disclosure with the reporter.

[report]: https://github.com/avenka29/gosync/security/advisories/new
